# Erdős-302: Harmonic Triple-Free Sets via Fractional Packing

This repository contains companion data and verification code for the study of the Erdős harmonic triple problem (also known as the Erdős-302 problem), which asks for the maximum density of a subset of {1, 2, ..., N} containing no harmonic triple (a, b, c) satisfying 1/a + 1/b = 1/c.

## Problem Background

A harmonic triple is a triple of positive integers (a, b, c) such that 1/a + 1/b = 1/c, or equivalently b*c = a*(b + c). The problem of determining the largest subset of [N] = {1, 2, ..., N} with no harmonic triple was posed by Erdős. Let f(N) denote the size of the largest such subset; we are interested in the asymptotic density lim sup f(N)/N.

## Method

We employ a **fractional packing argument** on the graph whose vertices are integers and whose edges correspond to harmonic triples. By constructing explicit fractional packings of harmonic triples within multiplicative semigroups generated by small sets of primes, we establish upper bounds on the deletion density and hence lower bounds on the density of harmonic-triple-free sets.

The certificates are constructed over "boxes" — sets of integers whose prime factorization involves only a fixed set of primes with bounded exponents. For each box, we provide a sequence of packing certificates at increasing thresholds, demonstrating that the packing number grows superlinearly and yielding a nontrivial deletion density D. The resulting upper bound on f(N)/N is 1 - D + o(1).

## Certificate Format

Each JSON certificate file contains:

- `primes`: the set of generating primes
- `dims`: the exponent bound for each prime (defining the box)
- `scale`: the scaling factor for fractional weights (fixed-point integer representation)
- `jumps`: a list of packing records, each containing:
  - `k`: the jump index (consecutive from 1)
  - `threshold`: the maximum vertex value in the packing
  - `packing`: a list of [[a, b, c], weight] entries, where (a, b, c) is a harmonic triple and weight is the fractional weight assigned to it
  - `value`: the total packing value (total weight / scale) as a rational string

## Verification

To verify the certificates independently:

```bash
python verify.py "box 2 3.json" "box 2 3 5.json" "box 2 3 5 7 11.json"
```

The checker uses only the Python standard library (`fractions`, `json`, `itertools`). It verifies:

1. Every triple in the packing is indeed a harmonic triple (1/a + 1/b = 1/c)
2. All three elements of each triple lie within the defined box
3. No vertex is loaded beyond the scaling factor (fractional packing constraint)
4. The packing value exceeds k - 1 at the k-th jump
5. The deletion density D and the resulting upper bound on f(N)/N are correctly computed

## Results

The certificates establish progressively stronger bounds as the set of generating primes grows:

- **{2, 3}**: baseline construction over a rank-2 semigroup
- **{2, 3, 5}**: improved bound with a third prime
- **{2, 3, 5, 7, 11}**: the strongest bound in this repository, using five primes

Refer to the paper for the precise numerical statements and proofs.
